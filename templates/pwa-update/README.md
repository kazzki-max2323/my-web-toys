# 更新がかならず届く PWA のひな形

スマホのホーム画面に追加できて、オフラインでも動き、**更新するとどの端末にも自動で新しい版が届く**ようにするためのファイルです。
「星降るイングリッシュ」で、端末によって更新されない問題を直したときのやり方をまとめました。

## 使い方

1. `sw.js` をアプリの `index.html` と同じフォルダにコピーする
2. `sw.js` の `CACHE` と `MEDIA` の名前をアプリごとに変える（例 `kanji-v1` / `kanji-media`）
3. `CORE` に、アプリの html・js・css・アイコン・manifest を並べる（音声・動画などの大きいファイルは入れない）
4. `register.html` の中身を `index.html` の `</body>` の直前に貼る
5. ゲームの途中で読みこみ直されると困るアプリは、`window.canReload=()=>いまホーム画面か` のような関数を用意する

**アプリを更新するたびに、`CACHE` の数字を1つ上げる**（`kanji-v1` → `kanji-v2`）。

## なぜこうするのか

| よくある作り方の問題 | このひな形 |
|---|---|
| インストール時にファイルを全部まとめて保存する → 大きいファイルが1つ失敗すると更新ごと止まり、古い版のままになる | 保存するのは画面の部品だけ。音声・動画は使ったときに保存 |
| 保存した古い版を先に表示する → 新しい版になるのが次に開いたとき | ネットの最新版を先に読みこむ（変わっていなければ304で軽い）。遅い・つながらないときだけ保存した版 |
| ホーム画面アプリは閉じないので、更新に気づかない | アプリにもどるたびに更新を確かめ、入れかわったら安全なときに1回だけ自動で読みこみ直す |
| 版を上げるたびに音声を全部ダウンロードし直す | 音声・動画は別の保存場所なので、版を上げても消えない |

## 古い仕組みのまま止まっている端末

一度だけ手で直す必要があります。ホーム画面アプリを完全に閉じて2回ほど開き直してください。
それでもだめなら（iPhone）「設定 → Safari → 詳細 → Webサイトデータ」でそのサイトを削除します（保存データも消えるので最後の手段）。
