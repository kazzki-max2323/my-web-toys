# 裏に回ったら音を止めるひな形

スマホでほかのアプリに切りかえたり、画面をロックしたり、別のタブを開いたりしたときに、
**ゲームの音（BGM・効果音・波の音・読みあげ）がすべて止まり、もどると再開する**ようにするためのファイルです。
「浜辺の英語」で、ほかのアプリに切りかえても音が鳴り続けていた問題を直したときのやり方をまとめました。

## 使い方

1. `bg-sound.js` をアプリのフォルダにコピーし、`index.html` で、音を鳴らすスクリプトより先に読みこむ
   ```html
   <script src="bg-sound.js"></script>
   ```
2. Web Audio を使うときは、`AudioContext` を作ったところで登録する
   ```js
   const ac = BgSound.add(new AudioContext());
   ```
3. `<audio>` / `<video>` と読みあげ（speechSynthesis）は、何もしなくても止まる
4. アプリにミュートボタンがあるときは、ミュート中にもどっても鳴らないようにする
   ```js
   BgSound.muted = () => !soundOn;
   ```

## なぜ必要か

ブラウザは、ページが裏に回っても Web Audio や `<audio>` の音を止めてくれないことがある（とくに Android）。
そのままだと、ほかのアプリを使っているあいだもゲームの音が流れ続けてしまう。
